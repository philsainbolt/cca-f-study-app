# CCA-F Study App

A free, unofficial practice app for the **Claude Certified Architect – Foundations (CCA-F)** exam.

**Use it:** open the GitHub Pages link for this repo, or download `index.html` and open it in any browser. It works offline.

> **Unofficial.** This project is not affiliated with, endorsed by, or connected to Anthropic. Every practice question is original study material written against the task statements in the public exam guide. None of it is real exam content, and none of Anthropic's sample questions are included.

## What's in it

- 177 original practice questions across the five exam domains, single-answer and multiple-response
- **Drill** by domain, task statement, scenario or question type, with an explanation for every option
- **Mock exams** (15, 30 or 60 items) with a countdown, flagging and a review screen, weighted by domain
- **Spaced review** on a Leitner schedule (1, 3, 7, then 14 days), with mastery after five correct in a row
- A **Blueprint** view of the task statements by ID and title, linked to drills

## Official exam guide

For the exam format, scoring, scenarios and the full task statements, use Anthropic's official guide:
[Claude Certified Architect – Foundations, Anthropic Partner Academy](https://anthropic-partners.skilljar.com/claude-certified-architect-foundations-certification)

## Privacy

`index.html` is one self-contained file. It makes no network requests and has no analytics. Your progress is saved only in your own browser (localStorage). You can export it from Settings and import it into another browser.

## Corrections

Spotted a wrong answer or an unclear question? Open an issue with the question ID shown in the app (for example `N-2.2-03`).
